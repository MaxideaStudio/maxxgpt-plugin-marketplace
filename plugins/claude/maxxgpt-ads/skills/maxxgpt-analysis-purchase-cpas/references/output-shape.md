# หน้าตาข้อมูลที่ได้จาก `get_job`

อ่านไฟล์นี้ตอนจะแปลงผลเป็นตาราง เพื่อรู้ว่าจะหยิบคีย์ไหน

> ## 🔑 กฎเดียวที่ห้ามข้าม
> **อ่านชื่อคีย์จากแถวจริงเสมอ** (`Object.keys(rows[0])`) แล้วค่อยเลือกคอลัมน์ตามตารางข้างล่าง ·
> ตารางนี้คือ *สิ่งที่คาดว่าจะเจอ* ไม่ใช่สัญญาตายตัว — ปลายทางเป็น flow ของเว็บ MaxxGPT
> ที่แก้ไขได้โดยไม่ผ่านสกิลนี้ · **คีย์ไหนไม่มี = ข้ามคอลัมน์นั้นไป ห้ามเดาค่า ห้ามคำนวณแทน**

`data` จาก `get_job` อาจมาเป็น **สตริง JSON → ต้อง parse ก่อน** · `{}` ว่าง = ไม่มีแถวเข้าเกณฑ์ (ไม่ใช่ error)

## รูปแบบรวม — หัวข้อ `purchase_cpas` (`analysis_purchase_cpas`)

```
{ "Ad":[...], "Adset":[...], "Campaign":[...], "Objective":[...],
  "Device":[...], "Position":[...], "Platform":[...],
  "Target":[...] }
```

- แต่ละคีย์เป็น **array ของ object** (1 object = 1 แถว)
- แถวระดับ **Ad มี `post_url`** ติดมาด้วย (บางแถวเป็นค่าว่างได้ = ดึงโพสต์ไม่ได้)
- 🔴 **หัวข้อนี้ไม่มี `Age` / `Gender`** — เป็นหัวข้อเดียวในตระกูลนี้ที่ไม่มี

## ⚡ เช็คก่อนว่า job นี้เป็นของหัวข้อนี้จริงไหม

ใช้ตอนที่ user ส่ง `job_id` มาให้ตรง ๆ — `get_job` **ไม่ได้บอกว่า job มาจาก tool ไหน**
เราจึงต้องดูจากรูปร่างของ `data` เอง

👉 **ตารางลายเซ็นเต็ม (ทุกหัวข้อ + สกิลที่ควรใช้) อยู่ใน [SKILL.md](../SKILL.md) § ทางลัด** — อ่านที่นั่นที่เดียว
เพื่อไม่ให้สองที่ขัดกัน

## คอลัมน์ของแถว Ad / Adset / Campaign

คอลัมน์ฐาน: `<level>_id`, `<level>_name`, `Spend`, `Impression`, `Clicks`, `CTR`
(ระดับ ad ใช้ `ad_id`/`ad_name`, ad set ใช้ `adset_id`/`adset_name`, แคมเปญใช้ `campaign_id`/`campaign_name`)

| เมตริกหลัก (ใช้เรียงลำดับ) | คอลัมน์ที่แนะนำให้โชว์ |
|---|---|
| `Purchase` | ชื่อ · `Spend` · `Purchase` · `Purchase_Value` (`money`) · `ROAS` (`num`) · `CTR` (`pct`) |

ชุดนี้คอลัมน์เฉพาะมีแค่ `Purchase` `Purchase_Value` `ROAS` (นอกเหนือจากคอลัมน์ฐาน) — **อย่าไปหา `Cost_per_purchase` ปลายทางไม่ได้ให้มา**

⚠️ `Impression` **ไม่มี s** · ชื่อคอลัมน์สะกดตามของจริง อ่านจากแถวจริงเสมอ

### 🔴 กับดักที่ทำให้อันดับผิด: ต้นทุนต่อผล = `0` เมื่อไม่มีผลลัพธ์

แถวที่เมตริกหลัก = 0 จะได้คอลัมน์ต้นทุนเป็น **`0` ไม่ใช่ `null`** → ถ้าเรียง "ต้นทุนถูกสุด"
จากน้อยไปมากตรง ๆ **แถวที่ไม่ได้ผลอะไรเลยจะขึ้นอันดับ 1**

**กติกา:** ก่อนเรียง/หา "ตัวที่ถูกที่สุด" ทุกครั้ง ให้ **ตัดแถวที่เมตริกหลัก = 0 ออกก่อน** ·
เวลาแสดงในตาราง แถวพวกนี้แสดง `0` ตามจริงได้ แต่ **ห้ามเรียกว่า "ต้นทุนต่ำ"** ·
แถวผล 0 **ยังนับรวมใน `Spend` รวม** — อย่าตัดออกจากยอดรวม (ตัดได้แค่ตอนเลือก 10 แถวมาโชว์)

## `Recomment` — **หัวข้อนี้ไม่มี**

ชุด `purchase_cpas` **ไม่มีคีย์ `Recomment`** — อย่าไปหา และไม่ต้องทำการ์ด "โฆษณาที่ระบบแนะนำ"

## Breakdown (การ์ดเล็กด้านล่าง — `sections`)

| คีย์ | 1 แถวคือ | คอลัมน์ |
|---|---|---|
| `Device` | อุปกรณ์ (`impression_device`) | ชื่ออุปกรณ์ + เมตริกหลัก |
| `Position` | ตำแหน่งวางโฆษณา (`platform_position`) | ชื่อตำแหน่ง + เมตริกหลัก |
| `Platform` | แพลตฟอร์ม (`publisher_platform`) | facebook / instagram / … + เมตริกหลัก |
| `Objective` | objective ของแคมเปญ | `Objective` + เมตริกหลัก |
| `Target` | กลุ่มเป้าหมายที่ยิง | `ID` `Name` `Type` `<เมตริกหลัก>` `Adset_IDs` |

breakdown ทุกชุดมีไม่กี่แถว → **ใส่ครบทุกแถวได้** ไม่ต้องตัด (ต่างจาก Ad/Adset/Campaign)

## จำนวนแถวที่ต้องคาด

`Ad` มาจาก Graph insights ระดับ ad `limit=500` → บัญชีใหญ่ช่วง 30 วันมีได้ **หลักร้อยแถว × ~18 คอลัมน์**
→ **ห้ามเทลงแชททั้งก้อน** (ดูกฎการตัดใน SKILL.md § 5)
