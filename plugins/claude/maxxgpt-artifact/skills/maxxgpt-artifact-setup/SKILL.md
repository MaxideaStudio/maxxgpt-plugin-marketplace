# ติดตั้งหรืออัปเดตเว็บ MaxxGPT Workspace

สกิลนี้เอาไฟล์หน้าเว็บที่มากับปลั๊กอิน maxxgpt-artifact ไป publish เป็น Artifact ในบัญชีของลูกค้า
ติดตั้งครั้งแรกกับอัปเดตใช้ขั้นตอนเดียวกัน ต่างกันแค่ว่ามีลิงก์เดิมให้ publish ทับหรือไม่

หน้าเว็บทำงานผ่าน connector ของลูกค้าเอง ชื่อ connector ตั้งเองได้และต่างกันทุกบัญชี
ถ้าประกาศชื่อผิด หน้าจะขึ้นว่า "ต่อ MaxxGPT ก่อนใช้เครื่องมือนี้" หรือถามสิทธิ์ซ้ำทุกครั้งที่เปิด
งานส่วนใหญ่ของสกิลนี้จึงอยู่ที่การหาชื่อให้ถูก และการเช็กว่า connector ใช้ได้จริงก่อน publish

## ขั้น 1 · หาชื่อ connector ของลูกค้า

อ่าน `sites/manifest.json` ในโฟลเดอร์ปลั๊กอิน (สองชั้นเหนือโฟลเดอร์ของสกิลนี้) แต่ละเว็บมี `connectors`
สามกลุ่ม แต่ละกลุ่มบอก `tools` ที่ใช้ และ `probe` คือ tool อ่านอย่างเดียวที่ใช้ลอง

| กลุ่ม | connector ที่มี tool นี้ | ต้องมีไหม |
|---|---|---|
| `maxxgpt` | `get_account_info` `list_ad_accounts` และ `fatigue_report` | ต้องมี |
| `meta` | `ads_get_ad_entities` และ `ads_update_entity` | ต้องมี |
| `drive` | `search_files` | ไม่มีก็ได้ สคริปต์จะใช้ชื่อ `Google Drive` ให้เอง |

**หาจาก tool ไม่ใช่จากชื่อ** เปิดรายชื่อ claude.ai connector ของเซสชันนี้ (สกิล `artifact-capabilities`
หรือเครื่องมือ Artifact บอกว่า connector ไหนชื่ออะไร) แล้วจับคู่ด้วย tool ที่มันมี ใช้ชื่อที่แสดงตรงตามตัวอักษร

- นับเฉพาะ claude.ai connector เท่านั้น MCP server ที่ปลั๊กอินติดตั้งไว้ในเครื่อง เช่น `plugin:maxxgpt-ads:maxxgpt`
  ใช้ในแชทได้ แต่หน้า Artifact เรียกไม่ได้ ห้ามเอามาใช้
- **อัปเดตเว็บที่มีอยู่แล้ว** หาเว็บเดิมตามขั้น 4 ก่อน แล้วอ่านชื่อ connector ที่เว็บเดิมประกาศไว้ ชื่อเหล่านั้นคือ
  ที่ลูกค้าเลือกไว้ตอนติดตั้ง ใช้ชื่อเดิมต่อถ้า connector ชื่อนั้นยังอยู่และมี tool ของกลุ่มนั้น ลูกค้าจะได้ไม่ต้องตอบซ้ำ
  บอกลูกค้าหนึ่งบรรทัดว่าใช้ชื่อเดิม ถ้าชื่อเดิมไม่มีแล้วหรืออ่านไม่ได้ ค่อยหาใหม่ตามข้อถัดไป
- กลุ่มไหนเจอ connector ที่ตรงมากกว่าหนึ่งตัว และไม่มีชื่อเดิมให้ใช้ ให้ถามลูกค้าว่าจะใช้ตัวไหน แสดงชื่อให้เลือก
  ห้ามเดาจากชื่อ และห้ามใส่สองตัว (บัญชีลูกค้าปกติมี MaxxGPT ตัวเดียว ถ้าเห็นหลายตัวมักเป็นบัญชีทีมงานที่มีตัวทดสอบ)
- ไม่เจอ MaxxGPT หรือ Meta ads ให้หยุด แล้วบอกลูกค้าให้ต่อ connector นั้นใน claude.ai ก่อน แล้วค่อยสั่งใหม่
- **connector MaxxGPT ต้องมี tool ครบทุกตัวใน `connectors.maxxgpt.tools` ของ manifest** เว็บรุ่นนี้เรียก `list_ad_accounts`
  `list_pages` และ `fatigue_report` ซึ่งมีเฉพาะ MaxxGPT รุ่นใหม่ (V4) ถ้า connector ของลูกค้าไม่มี tool เหล่านี้
  ให้หยุด ห้าม publish แล้วบอกลูกค้าว่า connector MaxxGPT ของเขายังเป็นรุ่นเก่า ให้ลบแล้วต่อใหม่ด้วย
  `https://mcp.maxxgpt.ai/mcp` (ต่อแล้วยังไม่มี ให้ติดต่อทีม MaxxGPT) ถ้า publish ไปทั้งอย่างนั้น แท็บ Creative Fatigue
  กับรายการบัญชีของ Ad Launcher จะใช้ไม่ได้
- บอกลูกค้าหนึ่งบรรทัดว่าเจอชื่ออะไรบ้าง ไม่ต้องให้เขาไปเปิดหาเอง

## ขั้น 2 · ลองเรียก connector ละหนึ่งครั้ง

เรียก `probe` ของแต่ละกลุ่มกับ connector ที่เลือก ด้วยค่าที่ schema ของ tool นั้นต้องการ
ถ้าเรียกไม่ผ่านแล้ว publish ไปก่อน ลูกค้าจะได้หน้าที่ล็อกหรือว่าง และจะไปไล่หาสาเหตุผิดที่

- **MaxxGPT `get_account_info`** อ่าน `code` ของคำตอบ ไม่ใช่เลข status อย่างเดียว
  - `code: SUBSCRIPTION_EXPIRED` (403) หรือ `reason: Close` ของระบบเดิม แปลว่าบัญชี MaxxGPT นี้ยังไม่มีแพ็กเกจที่ใช้ได้
    ให้หยุด บอกลูกค้าให้ติดต่อทีม MaxxGPT ห้าม publish
  - `code: NO_AD_ACCOUNT` (428) แปลว่าแพ็กเกจใช้ได้ แต่ลูกค้ายังไม่ได้เชื่อม Facebook หรือยังไม่ได้เลือกบัญชีโฆษณา
    ในเว็บ MaxxGPT (`reason: OVER_QUOTA` = ผูกบัญชีหรือเพจเกินจำนวนที่แพ็กเกจให้ ต้องไปเลือกตัวที่จะเก็บ)
    publish ต่อได้ แต่ต้องบอกลูกค้าว่าหน้าจะยังไม่มีข้อมูลจนกว่าจะไปทำขั้นนั้นในเว็บ MaxxGPT
  - error เรื่องล็อกอินหรือสิทธิ์ ให้บอกลูกค้าให้ต่อ connector MaxxGPT ใหม่
- **Meta `ads_get_ad_accounts`** ต้องได้รายการบัญชีกลับมา เรียกไม่ผ่านให้หยุดและบอกลูกค้าให้ต่อ Meta ads ใหม่
  (หน้าเว็บไม่ได้ใช้รายการนี้แล้ว รายชื่อบัญชีในหน้ามาจาก MaxxGPT แต่ Ad Launcher, Budget Scaling และ Kill Switch
  ยังสร้างและแก้โฆษณาผ่าน Meta ads จึงต้องเรียกได้)
- **Drive `search_files`** ลองเฉพาะเมื่อลูกค้ามี connector นี้ ค้นแบบเบา ๆ เช่นขอผลเดียว
  ถ้าไม่ผ่านให้เตือนหนึ่งบรรทัดแล้วทำต่อได้ เพราะ Drive ใช้แค่ในขั้นเลือกไฟล์ของ Ad Launcher
- connector หลุดล็อกอินระหว่างทาง ให้หยุดและบอกลูกค้า ห้ามสลับไปใช้ connector ตัวอื่นเอง

## ขั้น 3 · เตรียมไฟล์ด้วยสคริปต์

```
python3 "<โฟลเดอร์ของสกิลนี้>/scripts/prepare.py" workspace \
  --connector maxxgpt="<ชื่อ MaxxGPT>" --connector meta="<ชื่อ Meta ads>" \
  [--connector drive="<ชื่อ Drive ถ้ามี>"] --out "<โฟลเดอร์ชั่วคราว>"
```

สคริปต์ตรวจ sha256 ของหน้าเว็บในปลั๊กอินกับ manifest คัดลอกไฟล์ออกมาแล้วตรวจซ้ำ และใส่ชื่อ connector
ลงในรายการสิทธิ์ แล้วพิมพ์ JSON ที่มี `page` `title` `version` และ `capabilities`

- exit 2 ให้เอาข้อความใน `error` บอกลูกค้าตรง ๆ แล้วหยุด ห้ามแก้ไฟล์ให้ผ่านเอง
- publish จากไฟล์ `page` ที่สคริปต์คัดลอกให้เท่านั้น ห้ามพิมพ์หรือแต่งเนื้อไฟล์ขึ้นใหม่
  ไฟล์ใหญ่ราว 600 KB ถ้าเพี้ยนตัวอักษรเดียว หน้าอาจขาวทั้งหน้า
- ใช้ `capabilities` จาก JSON ทั้งก้อน ห้ามตัดหรือเพิ่ม tool

## ขั้น 4 · publish ทับลิงก์เดิม หรือสร้างใหม่ถ้ายังไม่มี

หา Artifact ของลูกค้าที่ชื่อ `MaxxGPT Workspace` ตรงตัว (ไม่นับชื่อที่มี `(dev)` หรือชื่ออื่น)

- **มีแล้ว** อ่านหน้าเดิมก่อน แล้ว publish ไฟล์ `page` ทับลิงก์นั้น พร้อม `capabilities` จากขั้น 3
  ถ้าถูกปฏิเสธเพราะหน้าเปลี่ยนหรือยังไม่ได้อ่าน ให้ publish ซ้ำแบบ force ได้ ข้อมูลที่ลูกค้าบันทึกไว้
  (ชุด interest ค่าเกณฑ์ รายการห้ามแตะ) อยู่ในฐานข้อมูลของหน้า ไม่หายเมื่อเขียนทับ และหน้านี้ไม่ publish ตัวเอง
  บอกลูกค้าหนึ่งบรรทัดว่าเขียนทับแล้ว
- **ยังไม่มี** publish เป็น Artifact ใหม่จากไฟล์ `page` ใส่ `capabilities` และใส่ icon ครั้งแรกนี้ครั้งเดียว
- ตอนอัปเดตห้ามส่ง contract หรือ icon ใหม่ ให้ค่าเดิมคงอยู่
- ห้ามสร้าง Artifact ตัวใหม่ทั้งที่มีตัวเดิมอยู่ ลูกค้าจะเปิดลิงก์เก่าที่บุ๊กมาร์กไว้แล้วเห็นของเก่า
  โดยคิดว่าอัปเดตแล้ว ถ้าหาตัวเดิมไม่เจอจริง ๆ ให้บอกชัดว่านี่คือลิงก์ใหม่

**อัปเดตหลังกด Update ปลั๊กอิน** ไฟล์ของปลั๊กอินโหลดตอนเริ่มเซสชัน ถ้าลูกค้าเพิ่งกด Update ในหน้า Plugins
ในเซสชันเดียวกันนี้ ให้บอกให้เปิดแชทใหม่แล้วพิมพ์ "อัปเดตเว็บ MaxxGPT" อีกครั้ง ไม่อย่างนั้นจะได้ไฟล์รุ่นเดิม
ถ้า `version` จากสคริปต์เท่ากับรุ่นของเว็บเดิม (ท้ายหน้าเขียนเลขรุ่น) ให้บอกลูกค้าว่าเว็บเป็นรุ่นล่าสุดที่ปลั๊กอินนี้มีอยู่แล้ว
การ publish ซ้ำยังมีประโยชน์เมื่อชื่อ connector เปลี่ยน ถ้าลูกค้าตั้งใจรับรุ่นใหม่ ให้เช็กว่ากด Update ปลั๊กอินแล้วและเปิดแชทใหม่

## ขั้น 5 · ให้ลูกค้าเปิดดูแล้วยืนยัน

ส่งลิงก์ให้ลูกค้า แล้วบอกสิ่งที่จะเจอ

- เปิดครั้งแรก claude.ai ขึ้นกล่องขออนุญาตใช้ MaxxGPT และ Meta ads ครั้งเดียว ให้กดอนุญาต
  (เห็นจริงบนบัญชีทดสอบ 2026-09-28) Google Drive จะถามเฉพาะตอนกดปุ่ม "ต่อ Google Drive แล้วค้นหา" ใน Ad Launcher
  และการใช้ Claude ช่วยร่างอาจถามตอนกดปุ่มของ Claude ครั้งแรก
- หัวเว็บเขียนว่า MaxxGPT Workspace และท้ายหน้ามีเลขรุ่นตรงกับ `version`
- แท็บ Interest Finder เปิดได้ และ Ad Launcher ขึ้นบัญชีโฆษณาที่ผูกกับ MaxxGPT
- แท็บ Creative Fatigue ขึ้นบัญชีที่เลือกไว้ใน MaxxGPT แล้วแสดงตารางภายในราวครึ่งนาที (MaxxGPT ดึงข้อมูลจาก Meta ให้เอง)
  บัญชีในเมนูคือบัญชีที่ผูกไว้ใน MaxxGPT เท่านั้น อยากเห็นบัญชีอื่นต้องไปผูกเพิ่มในเว็บ MaxxGPT
- ถ้าขึ้นว่า "ต่อ MaxxGPT ก่อนใช้เครื่องมือนี้" มักเป็นชื่อ connector ไม่ตรง ให้กลับไปขั้น 1
- ถ้าขึ้นว่า "บัญชี MaxxGPT นี้ใช้เครื่องมือนี้ไม่ได้" ให้ติดต่อทีม MaxxGPT
- หลังอัปเดต ด้านบนจะขึ้นว่าอัปเดตเป็นรุ่นไหนแล้ว

publish สำเร็จกับหน้าใช้งานได้เป็นคนละเรื่องกัน อย่าบอกว่าเสร็จจนกว่าลูกค้ายืนยันว่าเห็นบัญชีของตัวเองในหน้า
