# รูปแบบถาม (ปุ่มตัวเลือก) + รูปแบบผลลัพธ์ (ข้อความ + ตาราง)

🔴 **สกิลนี้ห้ามสร้าง widget / ฟอร์ม HTML / การ์ด UI ทุกชนิด** — ห้ามเรียก tool แสดงวิชวล
(`visualize` · `show_widget` · `render-ui` · Artifact) และห้ามเขียน HTML เอง

- **ถาม** = tool `AskUserQuestion` (ปุ่มตัวเลือก) เท่านั้น
- **ตอบ** = ข้อความ + ตาราง markdown ในแชทเท่านั้น

---

## § ถาม — ใช้ **AskUserQuestion** (ปุ่มตัวเลือก) เสมอ

🔴 **ห้ามพิมพ์คำถามเป็นข้อความเปล่า ๆ แล้วรอ user พิมพ์ตอบ** — ต้องเรียก tool `AskUserQuestion`
เพื่อให้ user **กดเลือกจากปุ่ม** · สกิลนี้แทบไม่ต้องถามอะไร
(tool รับได้สูงสุด 4 คำถาม/ครั้ง · คำถามละ 2-4 ตัวเลือก · ช่อง "Other" มีให้เองสำหรับพิมพ์เอง)

ถามเฉพาะที่ยังไม่รู้ · รู้แล้ว (user บอกมา / เคยได้ใน session นี้ / เดาจากบริบทได้) =
**ตัดคำถามนั้นทิ้ง อย่าถามซ้ำ** · รู้ครบทุกอย่าง = **ไม่ต้องเรียก tool เลย** ยิงต่อได้

**`spotlight_get` ไม่มีพารามิเตอร์เลย** (บัญชีมาจาก login · ช่วงเป็น preset ตายตัว) → ปกติ **ไม่ต้องถามอะไร ดึงมาแสดงได้เลย**

**ถามด้วย `AskUserQuestion` แค่กรณีเดียว:** บัญชียังไม่เคยรัน (`code: FUNCTION_NOT_RUN`)

| ฟิลด์ | ค่า |
|---|---|
| `header` | `รันสดไหม` |
| `question` | `บัญชีนี้ยังไม่เคยมีผล Ad Spotlight — ให้รันสดเลยไหม (ใช้เวลาสักครู่)` |
| `options` | `รันเลย` (ดึงผลล่าสุดให้ทันที) · `ไว้ก่อน` (ยังไม่รัน) |

**ถ้าเรียก `AskUserQuestion` ไม่ได้จริง ๆ** (ไม่มี tool / เจอ error) → fallback มีทางเดียวคือ
**ถามเป็นข้อความแบบเลขข้อ** แล้วหยุดรอคำตอบ:

```
ดูผลช่วงไหน — ตอบเลขข้อได้เลย
1) 7 วันล่าสุด (2026-08-30 → 2026-09-05)
2) 30 วันล่าสุด (2026-08-07 → 2026-09-05)
3) เดือนนี้ (2026-09-01 → 2026-09-06)
4) เดือนที่แล้ว (2026-08-01 → 2026-08-31)
5) ระบุเอง — บอกวันเริ่ม-วันจบมาได้เลย
```

- 🔴 **ห้ามสร้างฟอร์ม/widget แทนเด็ดขาด** แม้จะ "ดูดีกว่า" ก็ตาม
- **ต้องจบเทิร์นรอ user ตอบจริง ๆ** ห้ามเดาแล้วยิง tool ต่อเอง

## § ตอบ — โครงผลลัพธ์ที่ต้องพิมพ์

พิมพ์ 4 ส่วนตามลำดับ: **หัวเรื่อง → สรุปรวม → ตาราง → หมายเหตุ + ชวนถามต่อ**

### 1) หัวเรื่อง (2 บรรทัด)

```
## ✨ Ad Spotlight · โฆษณาแนะนำ · <ชื่อบัญชี> (<act_…>)
อัปเดตล่าสุด <Last_Update> · สกุลเงิน <CUR>
```

- ไม่รู้สกุลเงิน = เว้นไว้ **ห้ามเดาว่าเป็น THB**

### 2) สรุปรวม

1 บรรทัดต่อช่วงเวลา (จำนวนตัวที่เข้าข่ายแต่ละถัง) — **คำนวณจากข้อมูลเต็มก่อนตัดแถว** (รายละเอียดช่องไหนใส่อะไร ดู § กติกาตัดข้อมูล ใน `SKILL.md`)

### 3) ตาราง

เรียง 3 ช่วงเวลาเสมอ: `## เมื่อวาน (1d)` → `## 3 วันก่อน (3d)` → `## 7 วันก่อน (7d)`

แต่ละช่วงมีตารางย่อย: `### ควรปิด` (ยอดซื้อ / ทักแชท) · `### ควรผลักดัน` (ยอดซื้อ / ทักแชท) · `### ครีเอทีฟเด่น` (CTR / ทักแชท / ยอดซื้อ)

- **แต่ละถังเอา 6 แถวแรก** (เรียงมาให้แล้ว **อย่าเรียงใหม่** · ไม่ตัดแถวไหนออก — แถว `"รวม"` ก็เป็นโฆษณา) ·
  ตัดออก = เขียนใต้ตารางว่า `แสดง 6 จากทั้งหมด N`
- คอลัมน์ให้ใช้ตามที่ § 5 ใน `SKILL.md` กำหนด (4-6 คอลัมน์พอ) — **ห้ามยัดทุกคอลัมน์ที่มี**
- มี `post_url` = ทำชื่อโฆษณาเป็นลิงก์ markdown `[ชื่อ](post_url)` · ไม่มี = ชื่อเปล่า ๆ
- ค่าว่าง / `null` = `—` · ตารางที่ไม่มีแถว = เขียน "ไม่มีข้อมูลในช่วงนี้" แทนตารางเปล่า

**จัดรูปตัวเลขก่อนพิมพ์:** เงิน = ทศนิยม 2 ตำแหน่ง + สกุลเงิน · จำนวน = ใส่ลูกน้ำ ·
เปอร์เซ็นต์ = ทศนิยม 2 ตำแหน่ง + `%` (ค่าที่ได้มาเป็น % อยู่แล้ว **ห้ามคูณ 100**) · ROAS = เท่า ไม่ใช่ %

### 4) หมายเหตุ + ชวนถามต่อ

หมายเหตุเป็น bullet ขึ้นต้น `⚠️` (เงื่อนไขที่ต้องใส่ ดู § กติกาตัดข้อมูล ใน `SKILL.md`) แล้วปิดท้ายด้วยบรรทัดเดียว:

```
ถามต่อได้: สรุปสุขภาพโฆษณาโดยรวม · ขอรันใหม่ให้เป็นข้อมูลล่าสุด · ขอตารางเต็มทุกแถว
```
