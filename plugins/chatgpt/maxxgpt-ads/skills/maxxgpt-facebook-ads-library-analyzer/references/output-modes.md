# Output Modes — v3.8

## Default: Simple Report

The default report is for quick first-pass competitor research. It should be readable in about 2–3 minutes.

Show only:
1. **ภาพรวม**
2. **กลยุทธ์ Creative ที่เห็น**
3. **จุดแข็ง / จุดที่น่าระวัง**
4. **โฆษณาที่น่าศึกษาต่อ**
5. **สิ่งที่ควรไปดูต่อ**

### Plain-language rules
Prefer:
- `ข้อมูลที่เห็นยังไม่ครบ`
- `โฆษณาแนวเดียวกัน`
- `ตัวนี้น่าศึกษาต่อเพราะ...`
- `วิธีที่ใช้ดึงลูกค้าเข้ามา`
- `ใช้มุมขายนี้ซ้ำหลายตัว`

Avoid by default:
- Observability
- Clusterability
- Market Signal
- Strategic Quality
- Unique Cluster Share
- technical score tables

Technical logic can still run internally.

### Default top-ad format
For each of 3–5 recommendations:
- name/headline
- one short reason
- direct Ads Library link

No scoring table unless the user asks for scores.

## Deep Analysis

Use when the user wants detailed analysis from the Ads Library dataset itself.

May show technical measures, detailed cluster map, distributions, score rationale, chronology, and detailed confidence notes.

## Deep Research

Deep Research must add evidence, not only length.

When possible:
1. refresh Ads Library facts under the same scope
2. inspect representative Creative snapshots
3. inspect landing / offer pages
4. inspect current vs historical patterns
5. use relevant public page/site evidence
6. explain what changed after the deeper evidence

If deeper evidence is unavailable, state that briefly and deliver Deep Analysis instead.

## Mandatory closing for Simple Report

> **อยากดู Report นี้แบบ Deep Research ต่อไหม?** ผมสามารถเปิดดู Creative, ข้อเสนอ, หน้าเว็บ และหลักฐานอื่น ๆ เพิ่ม เพื่อเจาะว่าตัวไหนน่าศึกษาต่อและยังมีช่องว่างอะไรที่น่าสนใจ
