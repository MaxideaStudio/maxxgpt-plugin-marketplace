# รูปแบบถาม (ปุ่มตัวเลือก) + รูปแบบผลลัพธ์ (ข้อความ + ตาราง)

🔴 **สกิลนี้ห้ามสร้าง widget / ฟอร์ม HTML / การ์ด UI ทุกชนิด** — ห้ามเรียก tool แสดงวิชวล
(`visualize` · `show_widget` · `render-ui` · Artifact) และห้ามเขียน HTML เอง

- **ถาม** = tool `AskUserQuestion` (ปุ่มตัวเลือก) เท่านั้น
- **ตอบ** = ข้อความ + ตาราง markdown ในแชทเท่านั้น

---

## § ถาม — ใช้ **AskUserQuestion** (ปุ่มตัวเลือก) เสมอ

🔴 **ห้ามพิมพ์คำถามเป็นข้อความเปล่า ๆ แล้วรอ user พิมพ์ตอบ** — ต้องเรียก tool `AskUserQuestion`
เพื่อให้ user **กดเลือกจากปุ่ม** · ถามทุกอย่างที่ยังไม่รู้ **ในการเรียกครั้งเดียว**
(tool รับได้สูงสุด 4 คำถาม/ครั้ง · คำถามละ 2-4 ตัวเลือก · ช่อง "Other" มีให้เองสำหรับพิมพ์เอง)

ถามเฉพาะที่ยังไม่รู้ · รู้แล้ว (user บอกมา / เคยได้ใน session นี้ / เดาจากบริบทได้) =
**ตัดคำถามนั้นทิ้ง อย่าถามซ้ำ** · รู้ครบทุกอย่าง = **ไม่ต้องเรียก tool เลย** ยิงต่อได้

**คำถาม "วัดด้วยอะไร"**

| ฟิลด์ | ค่า |
|---|---|
| `header` | `วัดด้วยอะไร` |
| `question` | `จัดอันดับ Top Rank Ads โดยวัดด้วยอะไร` |
| `multiSelect` | `false` |

| `label` | `description` |
|---|---|
| `💬 ทักแชท (Inbox)` | จำนวนแชท + ต้นทุนต่อแชท |
| `📋 ลีด (Lead)` | จำนวนลีด + ต้นทุนต่อลีด |
| `🛍 ยอดซื้อ (Purchase)` | จำนวนการซื้อ + มูลค่าการซื้อ + ROAS |
| `💰 ROAS` | มูลค่าการซื้อ ÷ ยอดใช้จ่าย |

- **เดาได้ให้เดาก่อน อย่าถาม:** พูดถึงแชท = `inbox` · ลีด = `lead` · ยอดขาย = `purchase` ·
  คุ้มค่าโฆษณา/ROAS = `roas` → บอกหนึ่งบรรทัดว่าเลือกให้แล้ว

**คำถาม "ช่วงเวลา"** — ใส่ทุกครั้งที่ยังไม่รู้ช่วง

| ฟิลด์ | ค่า |
|---|---|
| `header` | `ช่วงเวลา` |
| `question` | `จัดอันดับจากผลช่วงไหน` |
| `multiSelect` | `false` |

| `label` | `description` |
|---|---|
| `7 วันล่าสุด` | `<วันนี้-7> → <วันนี้-1>` (เติมวันที่จริงลงไป) |
| `30 วันล่าสุด` | `<วันนี้-30> → <วันนี้-1>` |
| `เดือนนี้` | `<วันที่ 1 ของเดือน> → <วันนี้> · ข้อมูลยังไม่ครบเดือน` |
| `เดือนที่แล้ว` | `<วันที่ 1> → <วันสุดท้ายของเดือนที่แล้ว>` |

- **ใส่วันที่จริงลงใน `description` เสมอ** (คำนวณจากโซนเวลาบัญชี) user จะได้เห็นว่ากดแล้วได้ช่วงไหน
- อยากได้ช่วงอื่น (วันนี้ / เมื่อวาน / 14 วัน / ระบุเอง) → user พิมพ์ผ่านช่อง **Other** แล้วเราแปลงตามตารางข้างล่าง

**คำถาม "ยอดใช้จ่ายขั้นต่ำ"** — ใส่เมื่อจะกรองตัวเล็กออก (ไม่จำเป็นต้องถามทุกครั้ง)

| ฟิลด์ | ค่า |
|---|---|
| `header` | `ยอดขั้นต่ำ` |
| `question` | `ตัดแอดที่ใช้จ่ายน้อยกว่าเท่าไรออกไหม (หน่วย: <สกุลเงินบัญชี>)` |
| `options` | `ไม่กรอง (0)` · `300 ขึ้นไป` · `1,000 ขึ้นไป` |

- ไม่ถาม = ส่ง `spend=0` · **ตั้งค่าแล้วต้องเขียนในหมายเหตุว่ากรองที่เท่าไร** ไม่งั้น user งงว่าทำไมแอดหาย

**ถ้าเรียก `AskUserQuestion` ไม่ได้จริง ๆ** (ไม่มี tool / เจอ error) → fallback มีทางเดียวคือ
**ถามเป็นข้อความแบบเลขข้อ** แล้วหยุดรอคำตอบ:

```
ดูผลช่วงไหน — ตอบเลขข้อได้เลย
1) 7 วันล่าสุด (2026-08-30 → 2026-09-05)
2) 30 วันล่าสุด (2026-08-07 → 2026-09-05)
3) เดือนนี้ (2026-09-01 → 2026-09-06)
4) เดือนที่แล้ว (2026-08-01 → 2026-08-31)
5) ระบุเอง — บอกวันเริ่ม-วันจบมาได้เลย
```

- 🔴 **ห้ามสร้างฟอร์ม/widget แทนเด็ดขาด** แม้จะ "ดูดีกว่า" ก็ตาม
- **ต้องจบเทิร์นรอ user ตอบจริง ๆ** ห้ามเดาแล้วยิง tool ต่อเอง

---

### ช่วงเวลา — แปลงคำพูดเป็นวันที่

นับจาก **"วันนี้" ตามโซนเวลาของบัญชีโฆษณา** (จาก `get_account_info`) · แบบไม่รวมวันนี้ ตาม Ads Manager

| user พูด | `date_start` → `date_end` |
|---|---|
| วันนี้ | วันนี้ → วันนี้ |
| เมื่อวาน | เมื่อวาน → เมื่อวาน |
| 7 / 14 / 30 วันล่าสุด | `วันนี้-7` / `-14` / `-30` → `วันนี้-1` |
| เดือนนี้ | วันที่ 1 ของเดือน → วันนี้ |
| เดือนที่แล้ว | วันที่ 1 → วันสุดท้ายของเดือนที่แล้ว |
| ระบุเอง | ตามที่บอก (`YYYY-MM-DD`) |

- `date_start > date_end` = ถามกลับ อย่ายิง tool
- ช่วงที่ **รวมวันนี้** = ข้อมูลยังไม่ครบวัน → เขียนไว้ในหมายเหตุ
- ช่วง **เกิน 31 วัน** = เสี่ยงชนเพดานเวลา 5 นาที → เตือนหนึ่งบรรทัดก่อนยิง

## § ตอบ — โครงผลลัพธ์ที่ต้องพิมพ์

พิมพ์ 4 ส่วนตามลำดับ: **หัวเรื่อง → สรุปรวม → ตารางราย 3 ระดับ → หมายเหตุ + ชวนถามต่อ**

### 1) หัวเรื่อง (2-3 บรรทัด)

```
## 🏆 Top Rank Ads · <ชื่อบัญชี> (<act_…>)
ช่วง <date_start> → <date_end> · วัดด้วย <ชื่อเมตริกภาษาคน> · สกุลเงิน <CUR>
เรียงตาม **คุณภาพการส่ง (CPM + CTR)** ไม่ใช่ตามค่าเมตริก
```

- ไม่รู้ช่วงวันที่ (มาจาก `job_id`) = **เว้นไว้ ห้ามเดา** แล้วเขียนในหมายเหตุ
- ไม่รู้สกุลเงิน = เว้นไว้ **ห้ามเดาว่าเป็น THB**

### 2) สรุปรวม — ตารางเดียว 4 ช่อง

| ช่อง 1 | ช่อง 2 | ช่อง 3 | ช่อง 4 |
|---|---|---|---|
| จำนวนโฆษณาที่เข้าเกณฑ์ | ยอดใช้จ่ายรวมของกลุ่มนี้ | ผลรวมของ metric | ต้นทุนต่อผลรวม (หรือ ROAS รวม) |

```
| เข้าเกณฑ์ | ยอดใช้จ่ายรวม | ทักแชทรวม | ต้นทุนต่อแชท |
|---|---|---|---|
| 5 ตัว | 248,530.00 THB | 1,204 | 206.42 THB |
```

### 3) ตาราง 3 ระดับ

หัวข้อย่อยละระดับ: `### แคมเปญ` · `### Ad set` · `### โฆษณา` ·
**แต่ละระดับมีไม่เกิน 5 แถว พิมพ์ได้ครบ** (เรียงมาให้แล้ว **อย่าเรียงใหม่**)

คอลัมน์ 4-6 ช่องพอ: ชื่อ · `Spend` · **คอลัมน์ผลของ metric** · **คอลัมน์ต้นทุนของ metric** · `CTR` · `Score`

- ระดับ ad set / โฆษณา **ให้กำกับด้วย id ของแถวนั้น** (ชื่อซ้ำกันได้จริง — ad set ชื่อ `M-W` หลายตัว · โฆษณาชื่อ `-` · แถวไม่มีชื่อ/ID แคมเปญติดมา)
- มี `post_url` = ทำชื่อโฆษณาเป็นลิงก์ markdown `[ชื่อ](post_url)` · ไม่มี = ชื่อเปล่า ๆ
- ค่าว่าง / `null` = `—`
- ระดับที่ไม่มีข้อมูล = เขียน "ไม่มีข้อมูลในช่วงนี้" แทนตารางเปล่า

**จัดรูปตัวเลขก่อนพิมพ์:** เงิน = ทศนิยม 2 ตำแหน่ง + สกุลเงิน · จำนวน = ใส่ลูกน้ำ ·
`CTR` = ทศนิยม 2 ตำแหน่ง + `%` (ค่าที่ได้มาเป็น % อยู่แล้ว **ห้ามคูณ 100**) · `ROAS` = เท่า ไม่ใช่ %

### 4) หมายเหตุ + ชวนถามต่อ

หมายเหตุเป็น bullet ขึ้นต้น `⚠️` ใส่เมื่อ: ช่วงที่ขอรวมวันนี้ · ผลว่าง ·
ผลมาจาก job เก่า (`JOB_ALREADY_RUNNING`) · ผลมาจาก `job_id` ที่ไม่รู้ช่วงวันที่ · บัญชีไม่ ACTIVE ·
**ใช้ `spend` กรอง (บอกว่ากรองที่เท่าไร ไม่งั้น user งงว่าทำไมแอดหาย)**

ปิดท้ายด้วยบรรทัดเดียวว่าถามอะไรต่อได้ เช่น:

```
ถามต่อได้: ขอตารางเต็มทุกแถว · เปลี่ยนช่วงเวลา · เปลี่ยนเมตริก · เจาะแคมเปญตัวไหนเป็นพิเศษ
```

**ผลว่าง (`data` = `{}` หรือทุกชุดว่าง):** ยังพิมพ์หัวเรื่อง + สรุปตามปกติ แต่บอกเหตุผลแบบภาษาคน
"ช่วงนี้ไม่มีโฆษณาตัวไหนผ่านเกณฑ์ 'ทำได้ดี' ของเมตริกนี้" (ระดับไหนมีตัวที่ได้ผลลัพธ์ไม่ถึง 5 ตัว ปลายทางคืนว่างทั้งระดับ) → ลองเมตริกอื่น / ช่วงยาวขึ้น ·
**ถ้าตั้ง `spend` ไว้ให้ลองลดลงก่อนเป็นอย่างแรก**
